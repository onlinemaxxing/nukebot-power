# nukebot power

desenvolvido em python

Funcionalidades
excluir todos os canais / cargos
banir todos os membros
criar canais com rate limiting minimo etc
raid em geral 

clone o repositório:

git clone https://github.com/SEU_USUARIO/nukebot-power.git
cd nukebot-power

instale as dependências:

pip install -r requirements.txt

configure seu token:

altere o config.py

TOKEN = "SEU_TOKEN_AQUI"

Execute o bot: 

python main.py

Estrutura do Projeto
main.py      -> Arquivo principal
actions.py   -> Comandos e funções
config.py    -> Configurações do bot
Dependências
discord.py
colorama
Aviso

Mantenha seu token privado e nunca o envie para o GitHub.
